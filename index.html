Configurer Firebase (gratuit)

5 minutes pour activer la connexion par email et la synchronisation. Offre gratuite Spark suffisante.

  1. Créez un projet sur console.firebase.google.com (gratuit).
  2. Authentication → Sign-in method : activez Email/Mot de passe.
  3. Firestore Database → Créer une base (mode production), puis onglet Règles : collez ceci et publiez :
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid} { allow read, write: if request.auth != null && request.auth.uid == uid; } } }
  4. Paramètres du projet → Vos applications → Web (</>) : enregistrez l'app et copiez l'objet firebaseConfig.
  5. Authentication → Settings → Authorized domains : ajoutez votre domaine votre-pseudo.github.io (obligatoire pour GitHub Pages).

Votre configuration est déjà intégrée dans ce fichier (projet geoparts-11556). Cet assistant ne sert que si vous changez de projet un jour.
